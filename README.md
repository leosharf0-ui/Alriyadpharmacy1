# Alriyad Pharmacy

Arabic-first Android pharmacy app built with Kotlin + Jetpack Compose + Material 3.

## Included
- Blue/white Alriyad Pharmacy identity
- Home dashboard
- Categories
- Product catalog and details
- Search by product name / active ingredient
- Cart and WhatsApp order flow
- Direct phone calls
- WhatsApp contact
- Pharmacy address
- About/contact screen
- No hotline displayed
- Mock catalog ready to replace with a real backend/API/database

## Build
Open the folder in Android Studio and let Gradle sync. Build with `assembleDebug`.

The project follows current Android/Compose setup guidance: AGP 9.2.0, compileSdk 37, Kotlin 2.3.21, and Compose BOM 2026.06.00.
